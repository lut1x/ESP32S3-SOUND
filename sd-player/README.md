# SD-плеер для ESP32-S3-N16R8

Отдельная прошивка с нуля на ESP-IDF 5.5 / PlatformIO. Старый проект
`../firmware` не используется и не изменяется.

## Подключение по существующей схеме

- Линия 1 / I2S0: BCLK=3, WS=9, DATA=14; P2 = левый, P4 = правый.
- Линия 2 / I2S1: BCLK=5, WS=4, DATA=6; P3 = левый, P5 = правый.
- Два аппаратных I2S-контроллера и две задачи воспроизведения работают независимо.
  На линиях можно одновременно проигрывать разные файлы, даже с разными частотами
  дискретизации; выбор и громкость одной линии не меняют другую.
- SDMMC 4 bit, до 20 МГц: CLK=38, CMD=37, DAT0=39, DAT1=40, DAT2=35, DAT3=36.
  Это полная ширина шины microSD; 8-битный режим относится к MMC, не SD.
- PSRAM **отключена**. Включать её нельзя: GPIO35/36/37 используются картой.
  Установленная Octal PSRAM физически остаётся подключённой к этим выводам;
  работоспособность SD с отключённой PSRAM нужно проверить на конкретной плате.
  Успешная компиляция не подтверждает отсутствие аппаратного конфликта.
- UART0: 115200 бод. Дисплеи, AirPlay, Bluetooth и microSD SPI не используются.

## Сборка и загрузка

Откройте эту папку как отдельный проект PlatformIO. В PowerShell из этой папки:

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\python.exe" -m platformio run -e soundboard-sd
& "$env:USERPROFILE\.platformio\penv\Scripts\python.exe" -m platformio run -e soundboard-sd -t upload --upload-port COM7
```

Замените COM7 на порт платы. При необходимости зажмите BOOT и нажмите RESET
перед загрузкой; после загрузки отпустите BOOT и нажмите RESET.
Веб-страница встроена в приложение: **uploadfs не требуется**.

## Использование

1. Запишите WAV-файлы в корень карты FAT32. Поддерживается обычный RIFF WAV:
   PCM signed 16 bit little endian, моно или стерео, 8000–48000 Гц.
   Поддерживается также Extensible с PCM16. MP3/AAC/FLAC, float WAV и exFAT
   для воспроизведения пока не поддерживаются.
   В списке показываются первые 128 WAV-файлов; предпочтительны простые имена.
2. Вставьте карту при выключенной плате, затем подайте штатные 5 В.
3. Подключитесь к Wi-Fi **Soundboard-SD**, пароль **soundboard123**.
4. Откройте **http://192.168.4.1**. В карточке каждой линии выберите файл и
   нажмите «Играть по кругу». Либо используйте кнопки «Линия 1» / «Линия 2»
   рядом с файлом в общем списке.
5. У каждой линии отдельные пауза/продолжение, стоп, громкость и прогресс.

## Повтор и память настроек

Звук каждой линии повторяется автоматически. При достижении конца блока `data`
проигрыватель возвращается к его началу, не останавливая I2S и не вставляя паузу.
Заголовок и метаданные WAV не проигрываются. Счётчик повторов виден в интерфейсе.
Гладкость звука на стыке зависит и от самой записи: для бесшовного звукового
цикла начало и конец исходного WAV должны подходить друг к другу.

После успешного запуска выбранный файл сохраняется в NVS (во Flash платы).
Для каждой линии сохраняются также громкость, разрешение автозапуска и пауза:

- После перезапуска работавшая линия снова начинает тот же файл с начала.
- Пауза восстанавливается: линия остаётся на паузе, позиция начинается с нуля.
- «Стоп» отключает автозапуск, но сохраняет выбор файла и громкость.
- В новом проекте без сохранённых настроек обе линии выключены, громкость 25%.
- Положение внутри файла и счётчики повторов не сохраняются.
- Если карта или сохранённый файл недоступны, отображается ошибка; другой
  файл автоматически не подставляется. Выбор можно исправить в интерфейсе.

NVS записывается только при изменениях, не на каждом повторе или опросе состояния.
Дождитесь выполнения команды перед отключением питания. При ошибке сохранения
сообщение появляется у соответствующей линии. Обычная загрузка приложения
не стирает настройки; полное стирание Flash сбросит их.

## Загрузка файлов через браузер

При остановленных обеих линиях откройте «Загрузить музыку», выберите WAV-файл
на компьютере или телефоне и нажмите «Загрузить на карту». Показывается
прогресс передачи; затем прошивка проверяет формат WAV и сохраняет файл
в корень карты. Лимит — 2 ГБ минус 1 байт на файл, имя — до 255 байт UTF-8.
Свободного места должно хватать на весь файл. MP3 и другие форматы нужно
предварительно преобразовать в WAV, команда FFmpeg приведена ниже.

Файл с совпадающим именем не перезаписывается. Во время загрузки воспроизведение,
форматирование и другие команды недоступны. Кнопка «Отменить» прерывает передачу.
Файл сначала пишется во временный `.upload.tmp`; при обрыве или ошибке он
удаляется, а в список треков попадает только полностью принятый и проверенный WAV.
После потери питания временный файл может остаться и будет заменён при следующей
загрузке. HTTP-сервер принимает один файл за раз; опрос состояния в браузере на
время передачи приостанавливается. После завершения список обновляется.

Моно дублируется в оба канала выбранной линии. Извлечение/вставка карты
на ходу не поддерживается: для смены карты выключите питание.
Карта автоматически **не форматируется**. Форматирование доступно отдельно
в разделе «Подготовка SD-карты» веб-интерфейса.

## Форматирование в FAT32

1. Нажмите «Стоп» на обеих линиях, включая те, что стоят на паузе.
2. В разделе «Подготовка SD-карты» проверьте обнаруженный объём карты.
3. Нажмите «Форматировать в FAT32…» и введите `СТЕРЕТЬ` для подтверждения.
4. Дождитесь сообщения о завершении. Не отключайте питание и не вынимайте карту.

Это быстрое форматирование: таблица разделов заменяется одним разделом на весь
доступный объём, создаётся FAT32 с двумя копиями FAT и автоматически выбранным
размером кластера. Все старые разделы и файлы удаляются из файловой системы;
это не гарантированное физическое стирание содержимого секторов.
После форматирования карта повторно монтируется, список файлов обновляется.
Сохранённые выборы и автозапуск обеих линий очищаются: файлы были удалены.

Форматирование работает и при отсутствующей/повреждённой файловой системе
или исходной exFAT, если сам SD-контроллер успешно обнаружил карту.
Если карта электрически не отвечает, форматировать её невозможно.
Ошибки записи, слишком маленькая для FAT32 карта и ошибки повторного
монтирования отображаются в интерфейсе и журнале UART.
Операция выполняется в задаче первой линии, когда обе линии остановлены:
чтение каталога и новые команды блокируются до завершения. HTTP-сервер
продолжает выдавать состояние. Повторная команда форматирования отклоняется.

При отсутствии SD веб-интерфейс всё равно запускается и показывает ошибку.
Если карта обнаружена, можно подготовить FAT32 через веб-интерфейс.
Если не обнаружена — проверьте карту, контакты и журнал UART; затем
перезапустите устройство.

Для преобразования записи откройте `audio-converter.html` из этой папки обычным браузером:
выберите исходный файл, нажмите «Преобразовать в WAV», затем «Скачать WAV».
Конвертер работает локально, выдаёт WAV PCM16 stereo 44100 Гц и автоматически
выбирает имя латиницей. Полученный WAV загрузите в плеер.
Поддержка декодирования исходного аудио зависит от браузера.

Для FFmpeg:

```powershell
ffmpeg -i input.mp3 -ar 44100 -ac 2 -c:a pcm_s16le output.wav
```

## Две записи в одном стереофайле

**Веб-версия:** откройте `audio-merger.html` в браузере. Выберите первый файл
для левого канала и второй для правого, настройте тишину или повтор короткой
записи, нажмите «Собрать WAV», затем «Скачать готовый WAV». Результат можно
прослушать прямо на странице. Всё работает локально, установка Python/FFmpeg
для веб-версии не требуется. Форматы исходников определяются браузером.

`merge_audio.py` сводит первую запись в моно и помещает её **слева**, вторую
сводит в моно и помещает **справа**. Выход всегда WAV PCM signed 16 bit,
stereo, 44100 Гц — готов для нашего плеера. Исходные файлы не изменяются,
существующий выходной файл не перезаписывается.

Из этой папки:

```powershell
python merge_audio.py "left.wav" "right.wav" "combined.wav"
```

На этом Windows-компьютере можно запустить обёртку, которая сама найдёт
Python из PlatformIO:

```powershell
.\merge_audio.ps1 "left.wav" "right.wav" "combined.wav"
```

Длина результата равна длине более длинной записи. По умолчанию короткая
дополняется тишиной. Чтобы вместо тишины повторять короткую запись:

```powershell
python merge_audio.py "left.wav" "right.wav" "combined_loop.wav" --loop-shorter
```

Для PowerShell-обёртки тот же режим включается параметром `-LoopShorter`.

Для PCM WAV (8/16/24/32 bit, моно/стерео и многоканальных) достаточно Python.
Каналы исходника усредняются без дополнительного усиления. Если FFmpeg найден
в PATH, рядом со скриптом или указан через `--ffmpeg "C:\ffmpeg\bin\ffmpeg.exe"`,
он используется для декодирования и ресэмплинга ([параметры FFmpeg](https://www.ffmpeg.org/ffmpeg.html)), включая MP3/FLAC/другие
поддерживаемые им форматы. Без FFmpeg ресэмплинг PCM WAV выполняется простой
линейной интерполяцией; исходники 44100 Гц не требуют ресэмплинга.
Конвертер ничего не устанавливает и не загружает из интернета.

На линии 1 итоговый левый звук прозвучит на P2, правый — на P4;
на линии 2 — на P3 и P5 соответственно.

## Проверка на плате

Агентом пока не выполнена. Проверить: два разных WAV одновременно на P2/P4
и P3/P5, независимые громкость/пауза/стоп, повтор на конце файла и восстановление
выбора/громкости/автозапуска после выключения и включения питания. Проверить
также, что остановленная линия не запускается после перезагрузки, а поставленная
на паузу остаётся на паузе; загрузка/форматирование требуют остановки обеих линий.

Для теста каналов запустите `python make_test_wav.py` и скопируйте
`test-lr.wav` в корень карты. Сначала звучит левый канал (P2/P3), затем
секунда тишины и правый канал (P4/P5). Тестовый тон имеет плавные края.
