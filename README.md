## Распиновка по четырём схемам пользователя

| Сигнал | GPIO ESP32-S3 | Назначение |
|---|---:|---|
| BCLK1 | 3 | MAX98357A U3/P2 и U4/P4 |
| LRC1 | 9 | MAX98357A U3/P2 и U4/P4 |
| DIN1 | 14 | Данные от ESP к усилителям, это выход ESP |
| BCLK2 | 5 | MAX98357A U1/P3 и U5/P5 |
| LRC2 | 4 | MAX98357A U1/P3 и U5/P5 |
| DIN2 | 6 | Данные от ESP к усилителям, это выход ESP |
| UART0 RX | 44 | H2 контакт 3, через R7 100 Ом |
| UART0 TX | 43 | H2 контакт 2, через R8 100 Ом |
| BOOT | 0 | KEY2, подтяжка 10 кОм к 3,3 В |
| RESET | EN | KEY1, подтяжка 10 кОм к 3,3 В |
| Питание | — | H2: 1 GND, 4 +5 В; либо вход P1 |
| SD DAT2/DAT3/CMD | 35/36/37 | На N16R8 конфликтуют с Octal PSRAM! |
| SD CLK/DAT0/DAT1 | 38/39/40 | microSD не используется этой прошивкой |

Питание усилителей +5 В, ESP — через AMS1117-3.3. SD усилителей
подтянут к +5 В: U3/U1 через 100 кОм (левый канал), U4/U5 через
370 кОм (правый канал). GAIN по схеме не подключён.
Выходы SPK+/SPK− мостовые: каждый динамик подключать только между
контактами своей колодки; не соединять SPK− с GND или друг с другом.

## Что изменено

Конфигурация `soundboard-n16r8`: 16 МБ Flash, 8 МБ Octal PSRAM,
стандартный I2S Philips 16 бит stereo 44,1 кГц. MCLK не нужен.
I2S0 выводится на GPIO3/9/14, а его сигналы аппаратно дублируются
через GPIO-матрицу на GPIO5/4/6. Обе физические линии используют
одни такты и одни данные, без второго DMA и накопления рассинхронизации.
Все четыре усилителя работают: P2/P3 = L, P4/P5 = R.
В веб-интерфейсе можно выбрать Mono для одинакового L+R на всех выходах.
LED, дисплей, монитор батареи и управляющие GPIO сторонних DAC отключены.

Громкость задаёт только подключённый AirPlay-отправитель
(`CONFIG_AIRPLAY_SENDER_VOLUME_ONLY=y`). Сохранённый уровень платы не
восстанавливается; локальные команды изменения громкости отключены.
До первой команды громкости от отправителя новая сессия молчит.
0 дБ даёт точный коэффициент 1 без дополнительного ослабления или
усиления; отрицательные дБ преобразуются в амплитуду как 10^(dB/20).
Команда -144 дБ выключает звук. Сглаживание изменения уровня сохраняется.
На 100% прежний код тоже достигал коэффициента 1: программно увеличить
чистую выходную мощность сверх этого нельзя. GAIN MAX98357A задан
электрической схемой, а доступная мощность — питанием и нагрузкой.

Сеть, обнаружение AirPlay, декодирование, громкость, веб-настройки и OTA
предоставляет исходный проект AirPlay 2. Это не сертифицированный Apple продукт.
Для платы используется ESP-IDF, не Arduino sketch.

## Сборка

В PowerShell с установленным PlatformIO:

```powershell
cd C:\Users\lut1x1337\Documents\esp32s3_sound\firmware
python -m platformio run -e soundboard-n16r8
```

Если PlatformIO не находится в текущем Python, на этом компьютере:

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\python.exe" -m platformio run -e soundboard-n16r8
```

Профиль находится в `firmware/platformio.ini` и выбран по умолчанию.
Не собирать обычный профиль esp32s3: там чужая распиновка.
После смены профиля с уже созданным sdkconfig требуется чистая конфигурация.

## Первый запуск

Перед первым запуском отдельно загрузить файловую систему со страницами
веб-интерфейса. Обычный PlatformIO Upload загружает только приложение:

```powershell
pio run -e soundboard-n16r8 -t uploadfs
```

В VS Code: PlatformIO → Project Tasks → soundboard-n16r8 → Platform →
Upload Filesystem Image. Если подключены несколько COM-портов, добавить
`--upload-port COM7`, подставив свой порт. Перед загрузкой войти в BOOT,
после успешной загрузки нажать RESET. Без этого шага страница отвечает
`File not found`.

1. Подать штатные 5 В на звуковую плату.
2. Подключиться к Wi-Fi `ESP32-AirPlay-Setup` (изначально без пароля).
3. Открыть http://192.168.4.1, задать имя и домашнюю сеть Wi-Fi 2,4 ГГц.
4. Подключить iPhone/Mac к той же локальной сети и выбрать устройство
   `ESP32 AirPlay` (либо заданное имя) в списке AirPlay.
5. Начать с небольшой громкости. Для диагностики UART0 — 115200 бод.

microSD не нужна для AirPlay. На модуле N16R8 GPIO35–37 заняты PSRAM:
не инициализировать SD по этой разводке; карту убрать на время проверки.
Для будущей работы SD потребуется отдельная проверка/переделка разводки.

## Проверка

Работа на физической плате требует проверки после прошивки: появление точки
настройки, подключение AirPlay, звук с четырёх выходов, L/R тест и управление
громкостью. Результат сборки и ограничения записываются в BUILD_STATUS.md.
